# 2026-10-17 部署交接版

本轮在牌桌细化版本 `6f301f4` 上整理服务器交接，未改游戏规则和界面布局。

## 交付内容

- 根目录 `DEPLOY.md`：面向部署者的子域名、HTTPS、WebSocket、维护和回退说明。
- Dockerfile + Compose：Node 24、生产依赖、非 root 用户、健康检查、自动重启，本机绑定端口。
- `deploy/`：生产环境空白配置、Nginx 和 systemd 模板。
- `npm run check:deploy -- URL`：网页、管理员配置隔离、双人真实 WebSocket 牌局、底牌隔离和筹码守恒检查，不调用模型。
- `scripts/package-release.py`：从干净 Git 提交及已构建前端生成 ZIP、版本清单与 SHA-256，排除密钥和本地数据。

## 公网权限修复

此前仅检查服务端连接是否来自 loopback；同机反向代理可能让公网访问者被误判为本机管理员。

现生产模式 `NODE_ENV=production` 统一禁用网页修改模型配置和连接测试，部署者通过服务器环境管理密钥。非生产模式仍支持直接 localhost 访问管理；转发头、公网 Host 和跨来源访问都不能授予管理权限。WebSocket 单消息上限为 64KB。
