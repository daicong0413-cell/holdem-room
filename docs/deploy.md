# 公网部署

完整的朋友服务器 / 子域名部署指南见项目根目录的 [DEPLOY.md](../DEPLOY.md)。

发布包提供 Docker Compose、原生 Node.js 24、Nginx/WebSocket 配置、systemd 模板和上线验收脚本。使用独立子域名的根路径，部署前先阅读指南中的运行方式与重启限制。

关键事项：

- 公网部署必须设置 `NODE_ENV=production`，此模式禁用网页修改 API 配置和连接测试。由服务器 `.env` 管理密钥。
- 只运行一个实例，房间数据在内存中，重启会清空。
- 服务端端口只对本机开放，使用反向代理提供 HTTPS 和 WebSocket。
- 发布包不包含 `.env`、node_modules、浏览器配置或作者本地 `.git`。

若临时通过隧道测试，也必须先在生产模式下启动服务。代理或隧道连接可能来自本机，不能仅凭本机 IP 授予管理员权限。
